# CodeAlpha Web Scraping Project

## Project Overview

This project was developed as part of the CodeAlpha Data Analytics Internship.

The project uses Python, Requests, BeautifulSoup, and Pandas to scrape S&P 500 company data from Wikipedia and save it into a CSV file.

## Data Extracted

* Stock Symbol
* Company Name
* Sector
* Headquarters Location

## Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas

## Output

The extracted data is stored in:

`sp500_companies.csv`

## How to Run

1. Install dependencies:

```bash
pip install requests beautifulsoup4 pandas
```

2. Run the script:

```bash
python main.py
```
